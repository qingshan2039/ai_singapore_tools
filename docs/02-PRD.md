# PRD - TOTO Analyzer

## 一、产品定位

**一句话定位**：面向新加坡彩票数据爱好者的开奖数据查询与统计分析平台。

| 维度 | 决策 |
|---|---|
| 用户 | 数据爱好者（看图表、看趋势、看原始数据） |
| 形态 | Flutter 多端（Web 优先，移动端次之） |
| 模式 | 个人项目，免费，不商业化 |
| 立场 | 明确标注「仅供娱乐参考」，承认彩票本质是随机的 |
| 数据 | TOTO 优先，4D 后续，近 5 年数据起步 |

## 二、核心用户故事

| ID | 故事 | 优先级 |
|---|---|---|
| US-01 | 我想看最近一期 TOTO 开奖号码和奖金分布 | P0 |
| US-02 | 我想筛选某个时间段的历史开奖记录 | P0 |
| US-03 | 我想看每个号码（1-49）的历史出现频率热力图 | P1 |
| US-04 | 我想看最近 N 期没出现过的"冷号" | P1 |
| US-05 | 我想看号码间共现矩阵（哪两个号最常一起出） | P1 |
| US-06 | 我想看每期的奇偶比、大小比、和值、跨度 | P1 |
| US-07 | 我想用条件（奇偶比、和值范围等）随机生成一组号码 | P2 |
| US-08 | 我想登录后录入我买的号码，自动对奖 | P3 |
| US-09 | 我想在开奖后收到推送通知 | P3 |

## 三、功能模块

### 模块 A：数据展示
- 首页：最新一期结果 + 下一期开奖倒计时
- 历史列表：可按日期、号码筛选
- 单期详情：6 个中奖号 + 附加号 + 各奖级中奖人数与奖金 + 中奖店铺地图

### 模块 B：统计分析（核心差异化）
- 号码频率热力图（1-49 每个号码出现次数）
- 冷热号榜单（最近 N 期未出现 / 高频）
- 共现矩阵（49×49 热力图）
- 历史趋势：奇偶比、大小比、和值、跨度的时间序列
- 中奖号码与日期的关联（如周一 vs 周四是否有偏差）

### 模块 C：选号助手
- 机选（纯随机）
- 条件选号：限定奇偶比、和值区间、避开最近 N 期已开号
- 收藏号码组合

### 模块 D：个人功能（P3）
- Google / Apple 一键登录
- 投注记录录入与自动对奖
- 开奖通知推送

## 四、非目标（明确不做）

- ❌ 不做"预测下期号码"功能，避免误导用户
- ❌ 不做付费订阅、不做广告
- ❌ 不接入实际投注通道
- ❌ MVP 阶段不做社交功能（评论、社区）

## 五、成功指标（个人项目）

- 自己每周开奖后会主动打开看 → 产品有用
- 爬虫连续 3 个月零中断 → 技术稳定
 

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| Singapore Pools 反爬 / 封 IP | 低频抓取（开奖后 30 分钟跑一次），失败回退到手工录入 |
| 数据准确性出错 | 保留 raw_html 字段方便回溯；与第三方站交叉验证 |
| 法律合规 | 明确「仅供娱乐」声明；不商业化；遵守 robots.txt |
| 用户误把分析当预测 | 每个分析图表底部都加随机性免责声明 |
| 一个人维护时间不够 | 严格按 Roadmap，砍非核心功能 |
